# Атлас графиков

Широкий, расширяемый каталог семейств и вариантов, **не полный реестр всех когда-либо изобретённых графиков**. Названия разных школ могут обозначать одну форму. Каталог нужен для выбора; реализация пяти готовых шаблонов описана в `chart-selection.md`, остальных — в `advanced-rendering.md`. Ни один пункт сам по себе не означает готовую поддержку JSON-генератором.

Колонки: форма → когда выбирать → какие данные нужны / главный риск. Метки: **G** — готовый шаблон в пределах существующего input-контракта; **C** — индивидуальное построение; **S** — индивидуальное построение со специальными данными или расчётом. S не означает наличие отдельного установленного инструмента.

## 1. Сравнение, рейтинг, отклонение

| Форма | Задача | Данные / ограничение | Режим |
|---|---|---|---|
| Horizontal bar | Сравнить категории с длинными названиями | Категория + значение; длина от нуля | G |
| Column | Сравнить несколько категорий с короткими названиями | Те же данные; не путать категории с непрерывным временем | C |
| Grouped bars | Сравнить серии внутри категорий | Общие категории, единицы и период; много серий перегружает | C |
| Cleveland dot plot | Компактно сравнить уровни | Категория + число; подписанная общая шкала | C |
| Lollipop | Сравнить отдельные значения с акцентом на точке | Стебли от общей базы; размер точки не кодирует новое значение | C |
| Dumbbell | Показать разрыв между двумя значениями | Две сопоставимые оценки на одну сущность; легенда концов | C |
| Slope chart | Показать изменение между двумя срезами | Парные значения и одинаковые определения; подписать концы | C |
| Diverging bars | Показать отклонение от нуля / цели | Знаковые значения; явная точка отсчёта | C |
| Bullet chart | Факт относительно цели и диапазонов | Факт, цель, обоснованные границы; не выдумывать «хорошо/плохо» | C |
| Ranked table with in-cell bars | Сравнить точные числа по нескольким метрикам | Каждая колонка со своей подписанной шкалой | C |

## 2. Динамика и время

| Форма | Задача | Данные / ограничение | Режим |
|---|---|---|---|
| Single line | Изменение одного показателя | В готовом шаблоне только равномерные периоды; null — разрыв | G |
| Multi-series line | Сравнить несколько временных рядов | Реальные даты, единицы, прямые подписи; убрать путаницу линий | C |
| Step chart | Показать величину, меняющуюся в моменты событий | Время изменения + уровень; ступень отражает смысл данных | C |
| Area chart | Показать объём во времени | Нулевая база; заливка не должна скрывать другую серию | C |
| Stacked area | Изменение состава и общего объёма | Аддитивные непересекающиеся серии; средние слои трудно сравнивать | C |
| 100% stacked area | Изменение долей | Общий знаменатель на каждом шаге; абсолютный объём отдельно | C |
| Streamgraph | Обзор меняющегося состава многих потоков | Смещённая база; не для точного сравнения уровней | C |
| Bump chart | Изменение мест в рейтинге | Rank по периодам; показать ничьи, не выдавать rank за величину | C |
| Sparklines / small multiples | Сравнить форму многих рядов | Одинаковая шкала для сравнения величин; разные шкалы обозначать | C |
| Calendar heatmap | Найти календарный паттерн | Дата + значение, полный календарь; missing отличается от 0 | C |
| Gantt / interval timeline | Показать сроки и перекрытия | Начало, конец, сущность; проверить часовой пояс и границы | C |
| Cycle / seasonal plot | Сравнить повторяющиеся сезоны | Даты и цикл; не подменять сезонность недоказанной причиной | C |

## 3. Распределения

| Форма | Задача | Данные / ограничение | Режим |
|---|---|---|---|
| Histogram | Показать частоты значений | Наблюдения или корректные bins; ширина интервала влияет на вид | C |
| ECDF | Показать долю наблюдений не выше порога | Индивидуальные наблюдения; ось вероятности 0–1 или % | C |
| Box plot | Сравнить медианы и разброс | Наблюдения или корректные summary stats; указать правило whiskers | S |
| Violin | Сравнить формы распределений | Достаточно наблюдений; bandwidth влияет на форму | S |
| Strip plot | Показать сами наблюдения по группам | Один маркер = наблюдение; наложения и jitter должны быть понятны | C |
| Beeswarm | Развести перекрывающиеся наблюдения | Одна ось сохраняет величину; поперечное смещение не новая метрика | C |
| Ridgeline | Сравнить много распределений | Общий диапазон и правило плотности; сдвиг кривых пояснить | S |
| Density curve / KDE | Показать сглаженную плотность | Выбор ядра и bandwidth; не выдавать сглаживание за данные | S |
| Raincloud | Совместить наблюдения, плотность и сводку | Одна выборка для всех слоёв; риск перегруза на малом холсте | S |
| Q–Q plot | Сопоставить квантили распределений | Выборка и заданное распределение / вторая выборка | S |

## 4. Связи и многомерные данные

| Форма | Задача | Данные / ограничение | Режим |
|---|---|---|---|
| Scatter plot | Исследовать связь двух признаков | Парные x/y одной единицы; корреляция не причинность | C |
| Bubble plot | Добавить третью числовую величину | Площадь, не радиус, пропорциональна величине; size legend | C |
| Connected scatter | Показать траекторию двух признаков | x/y/time; подписать направление и порядок | C |
| Hexbin / 2D histogram | Показать плотность множества точек | Парные наблюдения, правила bins и colorbar | C |
| Correlation matrix | Обзор попарных связей | Метод коэффициента, sample sizes и missing policy; не только картинка | S |
| Scatterplot matrix | Сравнить пары нескольких признаков | Общие наблюдения; число панелей быстро растёт | C |
| Parallel coordinates | Сравнить многомерные профили | Шкалы / нормализация каждой оси явны; пересечения не значения | C |
| Radar / spider | Показать знакомой аудитории компактный профиль | Сопоставимые шкалы; площадь зависит от порядка осей; для точного сравнения лучше dots | C |

## 5. Состав и иерархии

| Форма | Задача | Данные / ограничение | Режим |
|---|---|---|---|
| 100% stacked bar | Показать состав одного целого | Непересекающиеся исчерпывающие части; сумма 100 | G |
| Absolute stacked bars | Сравнить объём и состав групп | Аддитивные значения в одинаковых единицах | C |
| Diverging stacked / Likert | Показать распределение ответов | Упорядоченные категории; явно разместить нейтральные ответы | C |
| Pie / donut | Показать несколько долей целого | Мало частей, сумма 100; не для близких значений или множества сегментов | C |
| Waffle / unit chart | Показать долю в дискретных единицах | Цена клетки и округление явны; не создавать ложную точность | C |
| Treemap | Показать веса внутри иерархии | Дерево + неотрицательный вес; площадь не подходит для тонких различий | C |
| Sunburst / icicle | Показать вложенные части | Единая иерархия; потомки согласованы с родителями | C |
| Marimekko / mosaic | Показать размеры групп и их состав | Ширина = размер группы, высота = доля; обе кодировки объяснить | S |

## 6. Потоки, этапы, пересечения и сети

| Форма | Задача | Данные / ограничение | Режим |
|---|---|---|---|
| Proportional funnel bars | Показать потери одной когорты по этапам | Последовательность с одной базой; убывающие значения | G |
| Sankey | Показать объём между узлами | source, target, weight; сохранение потока или объяснение потерь | S |
| Alluvial / parallel sets | Показать переходы категорий по стадиям | Связанные наблюдения / агрегированные пути; не соединять независимые маргинальные доли | S |
| Chord diagram | Обзор потоков между множеством групп | Матрица связей и направление; сложен для точного чтения | S |
| Node-link network | Показать структуру связей | Список узлов и рёбер; расстояния layout не считать измерением | S |
| Adjacency matrix | Сравнить плотную сеть связей | Одинаковые узлы по осям; направление, вес и порядок обозначены | S |
| UpSet plot | Сравнить пересечения множества наборов | Реальное членство / размеры пересечений; одиночных долей недостаточно | S |
| Venn / Euler | Объяснить немного пересекающихся множеств | Реальные пересечения; площади не считать точными без корректного построения | S |

## 8. Неопределённость, вклад и специальные задачи

| Форма | Задача | Данные / ограничение | Режим |
|---|---|---|---|
| Error bars / interval plot | Показать оценку и неопределённость | Метод и уровень интервала; SD, SE, CI и range не взаимозаменяемы | S |
| Fan chart | Показать диапазоны прогноза | Модель, горизонт, квантили; наблюдения отделены от прогноза | S |
| Forest plot | Сравнить оценки эффектов | Effect size, единицы, интервалы и reference line; pooling только по методике | S |
| Control chart | Следить за стабильностью процесса | Временной ряд и корректно рассчитанные control limits; не путать с CI/целями | S |
| Waterfall | Объяснить изменение от начала к итогу | Аддитивные вклады, корректные знаки, сходящийся итог | C |
| Pareto | Показать ранжированные вклады и накопленную долю | Аддитивные значения; cumulative от 0 до 100%, две шкалы подписаны | C |
| Cohort retention heatmap | Сравнить возвращаемость когорт по возрасту | Cohort sizes, return event, возраст; зрелость и missing отдельно от 0 | S |
| Kaplan–Meier / survival | Показать время до события с цензурированием | Время, статус события, правила цензурирования; не заменять retention-линейкой | S |
| Confusion matrix | Оценить ошибки классификации | Истинный/предсказанный класс; counts или явная нормализация по строкам/столбцам | S |
| ROC / precision–recall | Сравнить классификатор при разных порогах | Scores + labels, выборка и prevalence; не строить из одного процента accuracy | S |
| KPI strip | Показать несколько текущих уровней | Точная метрика и окно; тренд не выводится из одного значения | G |
| Annotated table | Показать точные данные и исключения | Единицы, сортировка, пропуски; график может быть не нужен | C |

## Правила вариативности

- Сначала вопрос: сравнение, изменение, распределение, связь, состав, поток, география или неопределённость. Затем конкретная форма.
- Для нового вопроса внутренне сравни хотя бы две разумные формы; выбери ту, где нужное различие проще увидеть. Не загружай пользователя списком альтернатив без причины.
- Не собирать весь отчёт автоматически из горизонтальных баров. Но одинаковые вопросы и сравниваемые панели сохраняют одинаковую форму, шкалу и порядок категорий.
- Комбинируй формы, когда вопросы различаются: уровень → KPI; распределение → histogram/ECDF; изменение → line; разрыв → dumbbell; вклад → waterfall. Не вводи квоту разных типов на страницу.
- Не достраивай отсутствующие данные ради эффектной формы. Из трёх средних не получится violin, из долей без пересечений — UpSet, из независимых агрегатов — Sankey.
- Для точного сравнения близких чисел предпочитай общую позиционную шкалу. Круги, площади, углы и потоки используй, когда они помогают именно поставленному вопросу.
- Малые множества, таблицы, подписи и аннотации — полноценные варианты. Редкая форма не является улучшением сама по себе.
- Inter, типографическая иерархия и смысл цвета сохраняются. Размер полотна и геометрия меняются под форму; матрицу нельзя втиснуть в слот трёх баров.
- 3D, перспективу, pictogram area, двойные оси и декоративные gauges не включать по умолчанию. По явному запросу объяснить ограничения и подписать кодировки; для пространственных научных данных 3D может иметь предметный смысл.
- Если подходящей формы нет в этом каталоге, найди первичный пример / документацию, проверь требуемые данные и построй её тем же расширенным маршрутом. Каталог не закрывает пространство вариантов.
