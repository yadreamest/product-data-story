# Редактура аналитического отчёта

Применяй к заголовкам, подзаголовкам, подписям, выноскам, легендам, источникам и финальному сообщению. Цель — конкретный, естественный текст, который помогает прочитать данные. Это редактура, а не попытка определить, кто написал текст.

## Обязательный проход перед экспортом

1. Для каждого предложения определи роль: факт, интерпретация, условие расчёта или действие. Если предложение не выполняет ни одной роли, удали его.
2. Проверь факты по данным. Не добавляй причины, точность, уверенность, рекомендации и оценки ради выразительного заголовка.
3. Замени абстракцию конкретным предметом, числом, периодом или действием. Если данных для такой замены нет, используй нейтральное название метрики.
4. Сократи повторы между заголовком страницы, заголовком блока и подписью. Не повторяй «База:» внутри поля base, «Источник:» внутри source: генератор добавляет эти префиксы сам.
5. Прочитай текст вслух: человек должен понять его с первого раза. Убери канцелярские обороты и неестественные связки. Сохрани принятую терминологию аудитории и конкретные названия продуктов.
6. Повторно сверь отредактированный текст с числами, единицами, знаменателем, периодом и ограничениями. Только затем экспортируй и проверь переносы в реальном изображении.

## Что убирать и чем заменять

Это признаки для проверки, не механический стоп-лист. Не удаляй точный термин только потому, что он встречается в списке.

| Слабая формулировка | Что делать |
|---|---|
| «Важно отметить», «Стоит подчеркнуть», «В целом можно сказать» | Начать сразу с факта |
| «Данные демонстрируют положительную динамику» | Назвать метрику и изменение; без чисел — «Динамика активации» |
| «Наблюдается увеличение показателя» | «Доля активных выросла с … до …» |
| «Значительный / существенный рост» | Указать величину; статистическую значимость писать только при проведённом тесте |
| «Открывает новые возможности», «создаёт основу для дальнейшего роста» | Удалить, если данные не задают конкретное действие |
| «Ключевой драйвер», «точка роста», «синергия», «экосистемный эффект» | Назвать наблюдаемый вклад или механизм; неизвестный механизм не придумывать |
| «Не просто X, а Y», «Это не про X — это про Y» | Написать прямое утверждение без риторического противопоставления |
| «Раскрыть потенциал», «вывести на новый уровень», «максимизировать эффективность» | Указать конкретную цель и способ проверки либо удалить |
| «Как мы видим на графике…» | Написать наблюдение без ссылки на собственный график |
| «Инсайты», «Выводы и рекомендации» как пустой заголовок | Назвать содержание блока; оставить такой заголовок, только если это нужная структура пользователя |

Не заменяй удалённый канцелярит разговорной грубостью, шутками, рекламой или искусственно рублеными фразами. Не запрещай все тире, пассивные конструкции и вводные слова: исправляй смысл и ритм, а не выполняй ритуал.

## Учебные примеры

Все числа ниже вымышлены. Пример можно использовать только при наличии соответствующих данных.

- Было: «Данные демонстрируют устойчивую положительную динамику активации». Дано: 22% в начале периода, 35% в конце, промежуточная неделя пропущена. Стало: **«Активация: 22% → 35%»**. Нельзя писать «устойчивый рост»: непрерывность не доказана.
- Было: «Наблюдается существенное снижение оттока на 4%». Дано: 12% → 8%. Стало: **«Отток снизился с 12% до 8%»** или **«Отток снизился на 4 п. п.»**. Относительное снижение — другой расчёт.
- Было: «Новая механика стала драйвером удержания». Дано: лишь две точки до/после. Стало: **«Удержание после запуска — 42%; до запуска — 38%»**. Отдельно: **«Причинная связь не проверена»**, если вывод о влиянии существенен для решения.
- Было: «Каждый пятый пользователь — новый». Дано: 22%, определение «нового» есть. Стало: **«22% пользователей — новые»**. Если определения нет: **«Доли аудиторных групп»** и локальная оговорка.
- Было: «Пользователи активно вовлекаются в разнообразные категории контента». Дано: музыка 64%, видео 38%, книги 21%. Стало: **«Музыку выбирают 64% пользователей»**. Под графиком: **«Можно выбрать несколько категорий»**.
- Было: «В рамках бенчмарка». Диапазон бенчмарка отсутствует. Стало: нейтральное название показателя; **«Диапазон бенчмарка не указан»** оставить рядом с числом.

## Оговорки без бюрократии

Не убирай неизвестную базу, разные окна, округление, пропуски, пересечения, малую выборку или источник под предлогом борьбы со слопом. Сформулируй ограничение один раз, кратко и рядом с затронутым графиком. Общую оговорку для всех блоков можно вынести в видимую общую подпись; локальные различия должны остаться локальными.

Не пиши одновременно «по представленным данным», «согласно исходному источнику», «на основании доступной информации» в каждом абзаце. Укажи источник и одно конкретное ограничение. «Нет данных за третью неделю» полезнее, чем «для всестороннего анализа необходимо учитывать ограничения имеющегося массива данных».

## Финальная проверка

- Каждый заголовок — проверяемый вывод или понятное название метрики.
- Числа, проценты / процентные пункты и периоды не изменились при сокращении.
- «Рост», «лучше», «эффективнее», «успешно» имеют явное основание и сравнение.
- Нет выдуманной причинности, статистической значимости и призывов «дальше улучшать» без конкретного основания.
- Подписи объясняют то, чего не видно из самого графика.
- Исходные цитаты и пользовательские формулировки не переписаны без пометки, если требуется сохранить их дословно.

## Минимум текста, максимум понятности

Главный принцип: читатель получает вывод без расшифровки графика. Предпочитай короткое наблюдение названию процедуры: «Каждый второй кликнувший подписался» вместо «Конверсия между этапами»; «Музыку чаще выбирают в первый день» вместо «Структура использования контента» — только если данные подтверждают частоту, период и сравнение.

- Один график — один короткий заголовок-вывод. Нейтральное название оставь, если вывод не доказан.
- Не заполняй свободное место текстом. Удали подпись, если без неё смысл и условия расчёта сохраняются.
- Не повторяй число в заголовке, выноске и заключении. Прямые значения на графике остаются для чтения и сравнения.
- «Больше всего», «чаще», «лучше конвертит» требуют явных сопоставимых альтернатив. Из высокого значения одного показателя превосходство не следует.
- Различай события и людей: «половина кликнувших подписалась» допустимо для пользователей; число кликов само по себе этого не доказывает.
- Базу, период и существенное ограничение оставляй кратко. Общую оговорку пиши один раз.
- Перед экспортом попробуй удалить каждое предложение. Если понимание не ухудшилось, удаляй.
