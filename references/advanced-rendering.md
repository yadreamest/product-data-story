# Расширенный режим построения

Каталог в `chart-atlas.md` — набор вариантов, которые агент может выбрать и построить. Это не список значений `type` для `scripts/render.py`. У готового JSON-генератора по-прежнему пять типов. Не отправляй `scatter`, `sankey` или `heatmap` в его схему и не заменяй нужный график барами только ради совместимости.

## Как выполнить запрос вне пяти шаблонов

1. Выбери подходящую форму по вопросу, структуре данных и аудитории. Наличие примера в галерее не доказывает, что форма подходит этим данным.
2. Сохрани нормализованные исходные данные в отдельный CSV/JSON с исходной точностью, единицами, периодами, source и population. Не своди наблюдения к средним, если нужен график распределения. Для нормализации сохрани исходные значения и формулу.
3. Создай **локальный скрипт для этого отчёта** в рабочей папке. По умолчанию используй установленный Matplotlib, шрифты Inter из `assets/fonts/`, токены из `design-system.md`. Не переписывай постоянный генератор скилла для одного отчёта.
4. Используй настоящий примитив графика: `scatter`, `hist`, `boxplot`, `violinplot`, `imshow`, `errorbar`, `fill_between`, `bar(..., bottom=...)`, `step`, `broken_barh`, полярную ось и т. п. Временная ось должна отражать реальные даты; нерегулярные даты нельзя подменять равномерными индексами. Для статистических графиков явно выбери расчёт, параметры, доверительный уровень и обработку пропусков.
5. Для интерактивности или сложных географических / сетевых схем выбери доступный подходящий инструмент, например Vega-Lite, Plotly, D3 или GIS-библиотеку. Проверь актуальную документацию и наличие runtime. Не требуй нового платного сервиса или публикации. Если нужен дополнительный пакет, установи только необходимое в окружение проекта в рамках доступных разрешений. При невозможности рендера укажи причину и предложи честную альтернативу.
6. Сохрани PNG и PDF, по возможности SVG, скрипт и входные данные. Используй новую папку; сначала рендер во временную, затем публикация после проверок, как в основном генераторе. Не оставляй старый статус успеха рядом с новым неуспешным экспортом.
7. Сам проверь арифметику и специфические инварианты из каталога. Открой реальный экспорт. Проверь оси, цвета, подписи, легенду, базу, размер текста и примечания. Только после этого называй график построенным. Проверка `validate()` из основного генератора **не проверяет** произвольные графики.

## Минимальная настройка Inter в Matplotlib

Этот фрагмент задаёт тему; сам график и работу с данными агент пишет под задачу.

```python
from pathlib import Path
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from matplotlib.font_manager import fontManager

skill_dir = Path('/absolute/path/to/product-data-story')  # resolve on this machine
for weight in ('Regular', 'Medium', 'SemiBold'):
    fontManager.addfont(str(skill_dir / 'assets' / 'fonts' / f'Inter-{weight}.ttf'))
plt.rcParams.update({
    'font.family': 'Inter',
    'figure.facecolor': '#FAFAF8',
    'axes.facecolor': '#FAFAF8',
    'text.color': '#202128',
    'axes.labelcolor': '#656872',
    'svg.fonttype': 'none',
    'pdf.fonttype': 42,
})
```

Не вставляй путь автора скилла. Встрой нужные параметры темы из текущей спецификации. Настройки OpenType, например табличные цифры, не считай включёнными без проверки.

## Быстрые маршруты

| Задача | Реализация | Проверить |
|---|---|---|
| Два числовых признака | `Axes.scatter(x, y)` | Одна точка = одна наблюдаемая единица; обе единицы подписаны |
| Распределение | `Axes.hist(samples, bins=...)` или `Axes.ecdf(samples)` | Не использовать средние вместо наблюдений; показать N и выбор bins |
| Интервалы / оценки | `Axes.errorbar(...)` | CI, SD, SE и range — разные величины; подписать именно рассчитанную |
| Парные значения | Точки и соединения по entity ID | Пары не сопоставлять по позиции после независимой сортировки |
| Waterfall | Бары с вычисленным bottom и отдельным итогом | Начало + изменения = итог; не складывать несопоставимые базы |
| Матрица | `Axes.imshow(...)` + colorbar | Пропуск / 0 / ещё не наблюдалось имеют разные состояния |
| Когорты | Маскированная матрица по возрасту когорты | Есть cohort sizes, событие возврата и маска незрелых ячеек |
| Временные интервалы | `Axes.broken_barh(...)` с датами | Конец ≥ начала; ось времени и часовой пояс определены |
| Потоки / сеть | Подходящий flow/network renderer | Сохранение количества, единицы потока, направления и пропуски |
| Карта | Координаты / геометрия + CRS | Проекция, границы, период и корректный знаменатель для rates |

## Статус возможностей

- **Готовый шаблон:** поддерживается текущим `render.py`, общий JSON-контракт.
- **Индивидуальное построение:** агент пишет и проверяет локальный скрипт; готового JSON-шаблона нет.
- **Требует специальных данных:** статистическая, сетевая или географическая структура ещё должна быть предоставлена / рассчитана; внешний вид нельзя имитировать выдуманными значениями.

Не называй каталог «поддержкой всех графиков в один клик». Не обещай общее время рендера для индивидуальных реализаций на основании скорости пяти готовых шаблонов.
